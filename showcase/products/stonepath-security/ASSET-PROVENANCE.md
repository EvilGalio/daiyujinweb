# Stonepath Security materials

Created 2026-09-10 for a fictional company. No real customer, employee, certification or report has been reused. Generated scene photographs are illustrative and are not portraits of the named fictional role profiles.

## Original documentary images

Generated with the built-in imagegen tool, default built-in mode (no API key or fallback CLI). Both images were actually inspected for appropriate subject, composition and plausible anatomy. No creative repair was required. Original PNGs and responsive WebP encodings are retained in assets/images/. prepare-assets.mjs uses the existing Sharp dependency to encode 1536px and 768px copies, without changing the scene.
